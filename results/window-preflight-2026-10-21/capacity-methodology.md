# Source-only capacity diagnostic

[`capacity.json`](capacity.json) preserves the source geometry calculated before
the complementary-window conditions were frozen. It binds the original saved
inputs, source hashes and extraction code. It covers 337 observed development
condition rows sharing 173 query units, plus 28 first-repetition urllib3 legacy
condition rows sharing 14 query units. These 365 rows represent 187 query units.

Only actual returned spans and already saved raw candidate windows were inspected.
Source bytes were checked against pinned file hashes. Canonical AST identities
distinguish windows of one definition from nested or separate definitions. Literal
connected unions require one path, overlapping or immediately adjacent physical
line ranges and identical bytes wherever ranges overlap. Their row and character
savings are capacity facts, not constructed responses or retrieval-quality gains.

No returned pair shares an actual definition, and no returned pair partially
overlaps, in either matrix. Most available union savings repeat the already known
nested containment cases. The only additional adjacency-only activation is one
Express query appearing in two observed conditions, joining two separate module
aliases. This provides little new room for a postpacking union pass alone.

For every delivered definition longer than 160 physical lines, the diagnostic
also inspected saved same-definition windows for a connected forward continuation.
Only five development condition rows and one urllib3 row have a different ranked
companion. At most one complete development suffix fits the unused characters
plus literal union savings; neither urllib3 example can fit its next physical
line. Token and metadata costs have not been applied to any hypothetical suffix.

The recorded urllib3 examples explain why prepacking and a source-preservation
guard are separate prospective experiments. The repeated-send `urlopen` windows
rank 11 and 22; neither is delivered, so an extension of a delivered anchor cannot
reach them. Other long excerpts stop because the character budget is exhausted,
despite unused compact tokens. This does not establish which experiment improves
quality. That requires the separately frozen all-condition replay and fresh test.

No new selector/postprocessor, model, index, retrieval, evidence scorer, rule
activation or network call was made for this diagnostic. The JSON records computed
aggregates rather than rerunning any new condition.
