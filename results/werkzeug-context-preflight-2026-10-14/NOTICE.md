Source-freeze.json binds52 tracked Python file hashes, their header fingerprints, the exact annotated/peeled Git objects/tree, current extractor bytes and its fingerprint. Source-only validation proves exact membership/spans/eligibility, not behavior under arbitrary runtime inputs or retrieval accuracy.

The three absence labels apply only to this source scope. HTTP/1.x server/WSGI adapters and routing websocket flags are not HTTP/2 framing/HPACK/multiplexing. The debugger's per-instance random secret and PIN cookie are related security mechanisms, but do not implement the requested per-session form-CSRF token lifecycle with login rotation. Static-file ETags/cache headers, Cache-Control serialization and request-body memoization are not a persistent full-response disk cache with upstream stale revalidation. External servers, frameworks, extensions and caller applications are excluded.

A neutral reviewer must check all positive local call paths and these absence distinctions before inference. Delegated standard-library cryptographic/parsing/I/O primitives and caller applications/storage factories are explicitly scoped in query notes; omitted local framing/charset/header helpers are identified where the query asks for orchestration or admission/control flow rather than their separate algorithm.
