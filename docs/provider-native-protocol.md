index for all arms. Original batch size four, maximum 8,192 tokens and padded
batch limit 8,192 remain fixed. Acquire the existing Git-common-directory GPU

- `legacy`: original ranked selection and unchanged postprocessor.
- `coverage_control`: current definition selection and source-preserving backfill.
- `original_role`: actual original live feature provider, exactly one semantic-v1
  proposal and the unchanged terminal state-write guard.
